# daytrade

Daily momentum screen for ultra-priced US large caps.

- `main.html` — always the latest recommendation
- `YYYY-MM-DD.html` — dated archive, one per trading day

## Honest note

The scoring model in this repo was backtested over 1 year (1,832 stock-days, 8 tickers).
It won 47–49% of trades and lost money at every threshold after costs.
The scores rank momentum. They do not predict next-day direction.

Educational analysis only. Not investment advice.
